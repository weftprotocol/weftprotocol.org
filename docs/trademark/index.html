Trademark policy

Draft. This policy has not been reviewed by a lawyer, and "Weft" has not been registered as a trademark. [REVIEW BEFORE PUBLISHING]

The Weft specifications are open: anyone may implement them, for any purpose, without asking. This page is only about the name "Weft" and the Weft logo, so people can tell what is compatible and who stands behind what.

You may, without asking

  • Say your software or host supports Weft, works with Weft, or implements the Weft Namespace, if it does.
  • Use the name in articles, talks, reviews and documentation about Weft.
  • Use the logo, unaltered, to link to weftprotocol.org or to show that a product supports Weft.

Please ask first before

  • Using "Weft" as the name, or the first word of the name, of your product, host or company (for example "Weft Cloud" or "WeftHost").
  • Using the logo as your own product's icon, or in a modified form.
  • Registering domain names that start with "weft" for a product or host.

Never

  • Suggest that your product is the official Weft software, or is run or endorsed by the Weft authors, when it is not.
  • Use the name or logo for something that does not follow the Weft specifications.
