What the reference server reads and writes

These are facts about the reference implementation, useful when building a compatible reader or writer. Only the feed format is the protocol.

  • Publishes RSS 2.0 only.
  • Reads RSS 2.0, RSS 1.0 (rdf:RDF) and Atom, in UTF-8, ASCII, ISO-8859-1/Windows-1252 and ISO-8859-15. From Atom it reads the title, link, logo, rel="next", entry text, dates, categories and thr:in-reply-to.
  • Webmention limits: 30 per minute per address (20 at once). Each user's inbox of unchecked Webmentions holds at most 500, and 50 from one host. Past that the server answers 503 with Retry-After: 300.
  • Not protocol: account moves, custom domains and the move code are server features. The protocol sees only the permanent redirect.

Listing rules

  • An implementation is listed if it reads or writes feeds that follow the Weft Namespace.
  • A host is listed if it follows Weft Hosting, including a complete export that another host can import.
