https://weftprotocol.org/ns/weft/0.1

This is the XML namespace URI for Weft Namespace 0.1. Declare it in an RSS 2.0 feed with the prefix weft:

<rss version="2.0"
  xmlns:weft="https://weftprotocol.org/ns/weft/0.1"
  xmlns:source="http://source.scripting.com/">

The full definition of every element is in the Weft Namespace 0.1 specification.

Parsers match on this URI, not on the prefix. A feed may use any prefix it likes, as long as it binds it to this URI.
